# AI Usage Disclosure

## Tools Used
- Claude (Anthropic) — claude.ai

## What AI Generated or Shaped
1. `indexer/pipeline/extract.py` — AI generated initial structure, we added the repeating header detection logic and OCR threshold.
2. `indexer/pipeline/chunk.py` — AI generated, we tuned the size/overlap parameters after running recall measurements.
3. `indexer/pipeline/embed.py` — AI generated, we added batch size tuning and the error message format.
4. `indexer/pipeline/store.py` — AI generated, we added the Redis FLUSHDB invalidation call.
5. `api/app/retrieval.py` — AI generated, we wrote the verify_embed_model guardrail logic ourselves.
6. `api/app/providers/llm/hosted.py` — AI generated structure, we wrote the prompt injection defence ourselves.
7. `api/app/services/cache.py` — AI generated.
8. `api/app/routes/` — AI generated, we wrote the /readyz dependency checks ourselves.
9. `eval/golden.yaml` — AI suggested question structure, we wrote every question ourselves based on real corpus content.
10. `docs/adr/` — AI generated initial drafts, we rewrote the reasoning in our own words.
11. `docs/ENGINEERING-NOTES.md` — AI generated structure, all answers cite our own code and reflect our understanding.

## What We Changed and Why
- **Prompt injection defence**: AI suggested schema constraints only; we added the explicit SECURITY NOTICE in the system prompt after reading the assignment's section 3.4.
- **OCR threshold**: AI used 50 chars; we lowered to 30 after finding a real document that had sparse text on some pages.
- **Cache threshold**: AI suggested 0.92; we verified with our own test questions and found 0.90 had a false hit.

## What AI Did Not Write
- `eval/golden.yaml` question content (written from real corpus).
- `corpus/MANIFEST.md` (generated by running fetch.py).
- `docs/evidence/` screenshots (taken from real cluster).
- Q7 in `ENGINEERING-NOTES.md` (a real bug we actually hit).
- `docs/CORPUS.md` property mapping (verified manually).
